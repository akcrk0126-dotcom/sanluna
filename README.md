# SAN LUNA

GTA 스타일 오픈월드 범죄 액션 (브라우저, three.js).

https://akcrk0126-dotcom.github.io/sanluna/

- `index.html` — 게임 화면 · HUD
- `gta/` — 도시 · 사람 · 차량 · 보행자 · 무기 · 경찰 · 미션 · 화면 · 소리
- 계정 · 레벨은 같은 사이트의 PlayHub 와 공유
